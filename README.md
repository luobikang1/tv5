# 🦊 白狐5 (WhiteFox 5) - 极速影视聚合平台

白狐5 是一款轻量、极速、高颜值的全网影视聚合播放平台。基于 React 18 + Vite + TypeScript + Tailwind CSS 构建，拥有强大的多端部署能力（Cloudflare Pages、Vercel、Docker、静态打包上传）与极致流畅的卡顿优化。

---

## 🌟 核心功能与亮点

- 🔒 **密码访问控制与多用户认证**：
  - 必须输入密码或用户登录才能开启面板，防止未授权访问与刷量。
  - 支持调用 Cloudflare D1 数据库实时保存用户注册、登录与观看进度。
- ⚡ **解决播放卡顿的三大核心技术**：
  ```text
  ┌────────────────────────────────────────────────────────────────────────┐
  │ 序号 │ 核心技术                 │ 作用与原理                          │
  ├──────┼──────────────────────────┼─────────────────────────────────────┤
  │  1   │ Nginx / Worker 代理缓存 │ 消除 CORS 跨域问题，缓存 m3u8 切片 │
  │  2   │ 预加载 + 预连接          │ preconnect 与 dns-prefetch 提前建连 │
  │  3   │ 多码率自适应 (低至 360P) │ 自动/手动切至 360P 流畅画质         │
  └──────┴──────────────────────────┴─────────────────────────────────────┘
  ```
- 🌐 **二十条互联网可用 API + 成人视频专栏**：
  - 自动加载 20 条优质 CMS 接口，支持在【设置】中一键添加自定义 API 或开启成人影片专栏。
- 🔍 **全站集合搜索与全网视频搜寻**：
  - 20+ 内置源并发检索，并支持搜索与在线播放全网网页/YouTube视频。
- 🎨 **白天/夜间模式切换与自定义背景**：
  - 支持日间/夜间深色主题与护眼调色盘。
- 🕒 **观看历史与单条/一键删除**：
  - 实时同步播放进度，支持单条记录删除或一键清空。
- ⏬ **下载中心与播放页返回主界面**：
  - 播放页提供一键返回主界面按钮、集数直链复制、上下集快速切换，下载页支持在线粘贴测试播放。
- 🖼️ **省流海报图**：
  - 采用轻量 SVG 占位与防盗链代理，完美解决海报加载失败或破坏布局问题。

## 🚀 部署指南 (简单易懂)

### 1. Cloudflare Pages 部署 (推荐，免费零成本)

#### 方式 A：GitHub 拉取关联部署（极简）
1. 将本项目 **Fork** 或 **Push** 到你的 GitHub 仓库。
2. 打开 [Cloudflare Dashboard](https://dash.cloudflare.com/) -> **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**。
3. 选择 `whitefox5` 仓库，设置构建参数：
   ```text
   ┌────────────────────────────────────────────────────────────────────────┐
   │ 构建选项              │ 填充值                                         │
   ├───────────────────────┼────────────────────────────────────────────────┤
   │ Framework preset      │ Vite                                           │
   │ Build command         │ npm run build                                  │
   │ Build output dir      │ dist                                           │
   └────────────────────────────────────────────────────────────────────────┘
   ```
4. 点击 **Save and Deploy** 即可完成部署！

#### 方式 B：直接上传 ZIP / `dist` 压缩包部署
1. 本地运行 `npm run build` 生成 `dist` 目录。
2. 在 Cloudflare Pages 选择 **Upload Assets** 直接拖拽上传 `dist` 文件夹或 Zip 包即可完成部署。

---

### 2. Vercel 一键部署

1. 在 Vercel 控制面板中导入本 GitHub 仓库。
2. 构建参数保留默认 (`npm run build` / `dist`)。
3. 环境变量可选填 `PASSWORD`。
4. 本项目已内置 `vercel.json` 规则，提交后项目将自动生成并运行服务端 API Proxy。

---

### 3. Docker & Docker-Compose 部署

拉取项目源码后执行：

```bash
docker-compose up -d --build
```
容器启动后直接访问 `http://你的服务器IP:8080` 即可享受支持 Nginx 缓存加速的白狐5面板。

---

## ⚙️ 恢复出厂设置

若需清空本地存储、重置 API 接口或清除密码，请前往 **【系统设置】 -> 【恢复默认设置】** 即可一键重置。
