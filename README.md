# 🦊 白狐5 (WhiteFox 5) - 极速影视聚合播放平台

白狐5 是一款专为极速响应与流畅观影打造的全网影视聚合播放平台（功能全面媲美月亮TV）。基于 **React 18 + Vite + TypeScript + Tailwind CSS** 开发，适配移动端与桌面端，提供无缝的在线播放、历史记录管理、全站聚合搜索与云端同步体验。

---

## 🌟 核心特性

- 🔒 **全局密码锁定与用户认证**：
  - 支持 **全局访问密码登录**（通过环境变量设置）与用户系统。
  - 防范未授权刷量，保护云服务器与 Worker 流量消耗。
- ⚡ **三大抗卡顿技术（解决源站慢与卡顿）**：
  1. **Nginx 代理缓存 / Cloudflare Worker 代理**：双端反查代理，解除跨域（CORS）与源站卡顿阻断。
  2. **预加载 + 预连接**：HTML 预解析与 HLS Buffer 预加载，大幅提升首帧加载速度。
  3. **多码率自适应切换（默认 360P）**：默认支持低至 **360P** 的流畅码率，弱网环境下秒开不卡顿。
- 🌐 **全网聚合搜索与二十条可用 API**：
  - 默认加载 20 条互联网可用 CMS 资源接口。
  - 在设置中可动态添加/重置 API 接口，并支持开启 **互联网成人视频专栏**。
  - 支持**全站一键聚合搜索**，快速匹配多源影片。
- 🎨 **白天/夜间模式 + 恢复默认设置**：
  - 支持一键切换深色/浅色主题。
  - 提供【恢复默认设置】功能，一键还原初始化配置。
- 🕒 **播放历史与删除管理**：
  - 自动记录观看进度与集数，支持单条删除或一键清空历史。
- ⏬ **下载与播放页联动**：
  - 播放页内置集数链接下载/复制功能，下载页支持 M3U8 在线测试与预览播放。
  - 播放页提供一键【返回主界面】与上下集快捷切换功能。
- ☁️ **Cloudflare D1 数据库同步**：
  - 支持绑定 Cloudflare D1 数据库，实现多端播放记录与用户配置同步。
- 🖼️ **省流海报图**：
  - 采用轻量化 SVG / 省流海报占位图，彻底解决海报图片不显示或加载缓慢的问题。

## 🚀 极简部署指南

本项目支持 **拉取部署（Git 集成）** 与 **上传部署（直接上传打包文件/Zip）**，适配各类主流平台。

### 1. Cloudflare Pages 部署（推荐，零成本）

#### 方式 A：GitHub 关联部署 (拉取部署)
1. 将本项目 Fork 或上传到你的 GitHub 仓库。
2. 打开 [Cloudflare Dashboard](https://dash.cloudflare.com/) -> **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**。
3. 选择 `whitefox5` 仓库，设置构建参数：
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
4. 点击 **Save and Deploy** 部署完成。
5. *(可选 D1 同步)*：在 Pages 项目设置 -> **Functions** -> **D1 database bindings** 中绑定名为 `DB` 的 D1 数据库。

#### 方式 B：直接上传部署 (上传部署)
1. 在本地运行 `npm run build` 生成 `dist` 目录。
2. 打开 Cloudflare Dashboard -> **Workers & Pages** -> **Create application** -> **Pages** -> **Upload assets**。
3. 将 `dist` 文件夹或压缩包直接拖拽上传即可完成部署。

---

### 2. Vercel 一键部署

1. 点击下方按钮或在 Vercel 导入本项目 GitHub 仓库：

   [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

2. 配置项目参数：
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Environment Variables**: 添加 `PASSWORD`（可选）
3. 点击 **Deploy** 即可一键上线！

---

### 3. Docker / Docker-Compose 部署

本项目内置支持 Nginx 代理缓存抗卡顿的 Docker 镜像配置。

```bash
# 1. 克隆/拉取仓库
git clone https://github.com/your-repo/whitefox5.git
cd whitefox5

# 2. 使用 Docker Compose 一键启动
docker-compose up -d --build
```

启动完成后，访问 `http://服务器IP:8080` 即可直接使用。

## ⚙️ 设置与维护

- **恢复默认设置**：进入【系统设置】-> 点击【恢复默认设置】按钮，可重置 API 接口与默认参数。
- **自定义 API / 成人专栏**：在【系统设置】中可任意添加或删除 CMS 接口，支持勾选自动加载互联网成人影片 API。
- **全局密码**：如需修改登录密码，可在部署平台修改 `PASSWORD` 环境变量或在系统设置中设定。
