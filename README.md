# 🦊 白狐5 (WhiteFox 5) - 极速影视聚合平台

**白狐5** 是一款轻量、极速、高颜值的全网影视聚合播放平台。采用 **React 18 + Vite + TypeScript + Tailwind CSS** 开发，专为流畅看片与极速响应打造。功能与月亮TV基本一致，支持拉取部署、上传部署、Cloudflare Pages 部署、Vercel 部署与 Docker 容器化部署。

---

## 🌟 核心特性

- 🔒 **密码保护与流量防护**：
  - 必须输入密码或登录后才能打开面板，有效防止未授权刷量，节省云平台流量。
  - 支持**全局访问密码**、**账号密码登录**与**新用户注册**。
  - 提供一键退出登录与面板锁定功能。

- ⚡ **解决卡顿三大核心技术（流畅看片）**：
  1. **Nginx 代理缓存 / Cloudflare Worker 代理**：通过代理路由解封 CORS 跨域限制，缓冲源站响应慢问题。
  2. **预加载 + 预连接 (Preconnect / DNS-Prefetch)**：提前对源站域名进行 DNS 解析与 TLS 握手建连，实现秒开播放。
  3. **多码率自适应切换 (默认 360P / 低至 240P-360P)**：针对弱网环境优化，默认 360P 流畅画质，支持 240P / 360P / 480P / 720P / 1080P 及自动码率无缝切换。

- 🎛️ **播放调节与卫视直播**：
  - **画质控制**：内置 240P、360P 省流、480P、720P、1080P 与 Auto 分辨率调节机制。
  - **画面与音量调节**：剧集列表上方直接配备画面亮度 (50%-150%) 与播放音量 (0%-100%) 滑块调节。
  - **全国卫视直播**：下载页内置 CCTV 与主流卫视频道（湖南卫视、浙江卫视、东方卫视等）在线直播与链接获取。

- 🌐 **自动抓取互联网新接口 + 成人专栏**：
  - 默认抓取并配置 20+ 条优质互联网影视 CMS 接口（自动按最低延迟优先排序）。
  - 设置页面支持【一键自动抓取互联网可用新接口】，检测连通性并支持一键保存与使用。
  - 支持开启【成人影片专区】，自动配置互联网成人影片 API 专栏。

- 🔍 **全网与全站集合搜索**：
  - 支持并发搜索 20+ 内置源站，快速找到所需影片。
  - 支持全网中英文视频与网页嵌入视频搜索（内置国内免代理镜像播放模式）。

- 🎨 **白天 / 夜间模式切换与恢复默认设置**：
  - 一键切换深色/浅色主题，支持自定义整站护眼背景色。
  - 支持【恢复默认设置】功能，一键还原出厂配置与重置接口。

- 🕒 **观看历史记录管理与下集切换**：
  - 自动保存播放进度与选集历史，支持单条历史记录删除、一键清空与播放页上下集快速切换。

## 📺 分辨率调节 (240P - 1080P) 的实现原理与说明

在播放器（HLS.js 引擎）中，**分辨率调节是否能真正生效**取决于源站 M3U8 的切片类型：

1. **主播放列表 (Master Playlist / 多码率流)**：
   - 当源站提供的 M3U8 包含多级分辨率切片（如 360P、720P、1080P index）时，白狐5 播放器会通过 `hls.currentLevel` **完全精准地切换至目标分辨率**，真正节省网络流量或提升画面清晰度。
2. **单码率流 (Single Level Stream)**：
   - 当源站切片本身仅输出固定分辨率（如源站仅切片了 720P 单码率）时，播放器将强制应用你所选择的预设，并根据源站最接近的 Level 呈现。
3. **默认分辨率策略**：
   - 系统默认全局画质设为 `360P` 省流模式，在进入播放页时自动选择低码率节点以实现秒播，用户亦可在右下角【设置/画质】菜单中随时手动切换至 720P / 1080P 高清模式。

## 🚀 极简部署指南

### 1. Cloudflare Pages 部署 (推荐，零成本、强兼容)

本项目专门优化了 Cloudflare Pages 部署兼容性，内置 `public/_redirects` 解决单页应用刷新 404 问题，内置 `functions/api/proxy.ts` 解决跨域代理问题。

#### 方式 A：GitHub 拉取关联部署 (自动构建)
1. Fork 或上传本项目源码到你的 GitHub 仓库。
2. 打开 [Cloudflare Dashboard](https://dash.cloudflare.com/) -> **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**。
3. 选择仓库 `whitefox5`，填写构建配置：
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
4. 点击 **Save and Deploy** 即可部署完成。

#### 方式 B：上传部署 (直接上传文件包)
1. 在本地运行 `npm run build` 生成 `dist` 产物文件夹。
2. 登录 Cloudflare Dashboard -> **Workers & Pages** -> **Create application** -> **Pages** -> **Upload assets**。
3. 输入项目名称（如 `whitefox5`），将 `dist` 文件夹打包或拖拽上传即可直接上线！

#### 绑定 D1 数据库 (可选，用于数据同步与注册)：
1. 在 Cloudflare Dashboard -> **Workers & Pages** -> **D1** 中创建一个名为 `whitefox5-db` 的数据库。
2. 在 Pages 项目设置中 -> **Settings** -> **Functions** -> **D1 database bindings** -> 变量名填 `DB`，绑定该 D1 数据库。

---

### 2. Vercel 一键部署

1. 登录 [Vercel](https://vercel.com/) -> 点击 **Add New** -> **Project** -> 导入 GitHub 仓库。
2. 参数配置：
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. 环境变量 (Environment Variables) 增加 `PASSWORD` (可选)。
4. 点击 **Deploy** 部署完成，内置 `vercel.json` 与 `/api/proxy.js` 将自动生效。

---

### 3. Docker & Docker-Compose 部署 (含 Nginx 代理缓存)

针对私有服务器部署，本项目提供带 Nginx 代理缓存的 Docker 环境：

```bash
# 1. 克隆 / 下载项目代码
git clone https://github.com/your-username/whitefox5.git
cd whitefox5

# 2. 启动 Docker 容器
docker-compose up -d --build
```
启动后即可通过 `http://你的服务器IP:8080` 访问白狐5面板。
