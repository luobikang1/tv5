# 🦊 白狐5 (WhiteFox 5) - 极速影视聚合平台

白狐5 是一款轻量、极速、高颜值的全网影视聚合播放平台。基于 React 18 + Vite + TypeScript + Tailwind CSS 开发，功能与月亮TV高度对齐，专为流畅看片与极速响应打造。

---

## ⚡ 解决播放卡顿的三大核心技术

1. **Nginx 代理缓存 / Cloudflare Worker 代理**：服务器端与 Worker 自动反查代理，解除跨域（CORS）与源站响应缓慢问题。
2. **预加载 + 预连接**：HTML 头部注入 `preconnect` 与 `dns-prefetch`，HLS.js 引擎自动实施分段预加载。
3. **多码率自适应 (低至 360P)**：默认开启 360P 流畅码率，弱网环境下自动切换低码率，保证播放不卡顿。

## 🚀 部署指南 (简单易懂)

### 1. Cloudflare Pages 部署 (推荐，零成本)

Cloudflare Pages 提供两种极简部署方式，已内置 `public/_redirects` 路由重定向与 API Functions：

#### 方式 A：GitHub 关联拉取部署 (自动更新)
1. 将本项目 Fork 或 Push 到你的 **GitHub** 账号。
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/) -> 点击 **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**。
3. 选择 `whitefox5` 仓库，配置构建参数：
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
4. 点击 **Save and Deploy** 即可完成部署！

#### 方式 B：静态文件上传部署 (无需 Git)
1. 本地运行 `npm run build` 生成 `dist` 目录。
2. 在 Cloudflare Pages 中选择 **Upload assets**。
3. 直接将 `dist` 文件夹或压缩包拖拽上传即可完成部署。

> **Cloudflare D1 数据库绑定（可选）**：
> 进入 Pages 项目设置 -> **Functions** -> **D1 database bindings** -> 绑定变量名为 `DB` 的 D1 数据库，即可开启注册与观看历史多端同步。

---

### 2. Vercel 一键部署

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new)

1. 点击上方或在 Vercel 中导入本 GitHub 仓库。
2. 构建参数保留默认值：
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. （可选）环境变量中添加 `PASSWORD`。
4. 点击 Deploy 即可。已内置 `vercel.json` 规则，路由重定向与 `/api/proxy` 函数将自动生效。

---

### 3. Docker & Docker-Compose 部署

本项目已内置配合 **Nginx 代理缓存 (Anti-Lag)** 的 `Dockerfile` 与 `docker-compose.yml`：

```bash
# 克隆仓库并直接启动 Docker
docker-compose up -d --build
```
启动后直接访问 `http://你的服务器IP:8080` 即可。

## 🌟 核心功能清单

- 🔐 **密码保护**：支持密码锁控制，防止未授权人员访问与流量刷取。
- 🎬 **多码率自适应与画质调节**：默认 360P，可调至 480P、720P、1080P 或自动。
- 🔍 **全站集合搜索 & 全网搜索引擎**：并发抓取 20+ 内置源站，并支持全网与 YouTube 视频内嵌播放。
- 🌙 **日间 / 夜间模式**：支持一键切换主题与背景调色盘。
- 📜 **历史记录与单个删除**：自动记录进度，支持删单条或一键清空。
- ⏬ **下载中心与播放页解析**：播放页提供直链复制与下载，下载页支持 M3U8 在线播放与预览。
- 🏠 **播放页返回主界面按键**：播放页提供“返回上一页”与“返回主界面”双按键。
- ⏭️ **上下集一键切换**：快速切换上一集/下一集。
- 🖼️ **省流海报图**：SVG 省流占位图，彻底解决海报图片裂开与加载失败。
- 🔞 **成人视频专栏**：可在设置中开启成人专栏，自动加载互联网成人影片 API。
- 🔄 **恢复默认设置**：支持一键恢复出厂配置与默认 20 条 API 接口。
