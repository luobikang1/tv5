# 🦊 白狐5 (WhiteFox 5) - 极速影视聚合平台

白狐5 是一款轻量、极速、高颜值的全网影视聚合播放平台。采用 React 18 + Vite + TypeScript + Tailwind CSS 开发，专为流畅看片与极速响应打造。

---

## 🌟 核心特性与三大防卡顿技术

1. **⚡ 三大播放卡顿解决方案（流畅看片）**：
   - **Nginx / Cloudflare Worker 代理缓存**：通过反向代理与缓存机制解除 CORS 跨域限制与源站响应慢问题。
   - **预加载 + 预连接 (Preconnect & DNS-Prefetch)**：在 HTML 中提前为主要源站建立 TCP/TLS 连接。
   - **多码率自适应切换 (默认 360P)**：内置低至 360P 的流畅码率选项，弱网环境下自动选择或切换最匹配流畅度的清晰度。

2. **🔒 多重登录与访问保护面板**：
   - 支持**全局独立访问密码**、**账号注册与登录**。防止未授权刷量，节省云服务流量。
   - 支持一键退出登录与面板锁定。

3. **🌐 二十条互联网可用 API + 成人视频专栏**：
   - 默认自动配置 20 条优质 CMS 接口，支持全站并发聚合搜索。
   - 在【系统设置】中可一键开启**成人视频专区**，自动加载互联网成人影片 API。

4. **🎨 护眼白天 / 夜间模式切换与恢复出厂设置**：
   - 快速切换浅色与深色主题，支持背景调色盘。
   - 提供【恢复默认设置】功能，一键还原出厂配置。

5. **🕒 观看历史记录与单条/批量删除**：
   - 自动记录每部影片播放历史与剧集进度，支持单独删除与一键清空。

6. **⏬ 下载中心与在线解析播放**：
   - 播放页提供集数直链复制与一键跳转下载页。
   - 下载页支持粘贴 M3U8 / MP4 链接直接预览播放与高速下载。

7. **🖼️ 省流海报图与防盗链优化**：
   - 内置高质感 SVG 省流占位图与图片代理，彻底解决海报破损与加载失败问题。

8. **☁️ Cloudflare D1 数据库实时同步**：
   - 支持绑定 Cloudflare D1 数据库，实现跨设备注册登录与历史进度同步。

## 🚀 部署指南 (Deployment Methods)

### 1. Cloudflare Pages 部署 (推荐，零成本)

本项目包含针对 Cloudflare Pages 优化好的配置文件 (`public/_redirects`, `public/_routes.json`, `functions/api/proxy.ts`, `functions/api/d1/sync.ts`)。

#### 部署步骤：
1. Fork 或上传本项目到你的 **GitHub** 账号。
2. 打开 [Cloudflare Dashboard](https://dash.cloudflare.com/) -> 进入 **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git**。
3. 选择 `whitefox5` 仓库，设置构建配置：
   - **Framework preset**: `Vite`
   - **Build command**: `npm run build`
   - **Build output directory**: `dist`
4. 点击 **Save and Deploy** 即可完成部署！
5. **(可选) 绑定 D1 数据库**：
   - 在 Pages 项目设置中点击 **Functions** -> **D1 database bindings** -> 添加变量名 `DB` 绑定至你的 D1 数据库。

---

### 2. Vercel 一键部署

1. 在 Vercel 中导入 GitHub 仓库。
2. 配置构建参数：
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
3. 在 Environment Variables 中添加 `PASSWORD`（可选）。
4. 本项目已内置 `vercel.json` 配置文件，一键部署后路由与 `/api/proxy` 接口将自动运行。

---

### 3. Docker & Docker-Compose 部署

本项目已内置带有 **Nginx 代理缓存 (Anti-Lag)** 的 `Dockerfile` 和 `docker-compose.yml`。

#### 拉取并一键运行：
```bash
# 拉取源码并启动 Docker 容器
docker-compose up -d --build
```
启动后访问 `http://服务器IP:8080` 即可观看。

## ⚙️ 恢复默认设置与注意事项

- **恢复默认设置**：若遇到设置异常，点击顶部导航【系统设置】-> 滚动至底部点击【恢复默认设置】，可重置 API 接口与清空本地缓存。
- **防止跨域卡顿**：播放器内置代理反查按键，若源站存在跨域阻断或响应慢，可点击播放器右下角【启用极速代理】开启流畅播放。
